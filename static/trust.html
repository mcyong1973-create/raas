How It Works

1. Agents Self-Report
Agents record tasks and mistakes to RaaS ledger. This is what they claim they did.
2. Observer Reads Logs
Script runs every 6 hours reading Hermes agent.log, Sage cron.log, and Forge/Beacon JSONL ledgers independently.
3. File Integrity Check
SHA-256 checksums of 65 critical files across all agent workspaces. New, modified, or missing files flagged each cycle.
4. Discrepancy Report
Compares reported claims vs observed actions. Flags under-reporting, unlogged errors, and file changes.
Method Statement: The Observer is an independent Python script that reads system-level log files. It has no access to agent memory, no API keys, and cannot be influenced by agent prompts. Its own ledger is written to ledger-observer.jsonl and its source code is at ~/.hermes/scripts/observer-v2.py. Anyone can verify the Observer's findings by reading the same log files. The Observer itself is tracked by the same cron system as the agents it monitors — if the Observer stops running, that gap is itself detectable.
